# Canteen Sim — Plan 4: The App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the page (spec §9.3–9.4, §10.5–10.8 UI, §11, §13.6, §13.8, §14): a single self-contained
`dist/index.html` with two linked 3D canteens, live counters and charts, the settings drawer, the Assumptions panel,
the batch view with precomputed evidence, browser tests, and a private claude.ai artifact.

**Architecture:** Preact + signals for panels (`src/ui`), three.js for the scene (`src/render`), both consuming the
engine only through `createEngine`'s interface and `view()`. A playback controller owns the two engines and the frame
loop. Batch runs go through Plan 3's executors: an inline worker pool (`?worker&inline`) with the time-sliced
main-thread fallback. Config sharing uses the URL hash (standalone page) and the settings code (everywhere, including
the artifact sandbox, which strips `#key=value` hashes).

**Tech Stack:** Vite 7 + vite-plugin-singlefile, three.js 0.186, Preact 10 + @preact/signals, uPlot 1.6, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-24-canteen-sim-design.md`.

**Plan form (ruling, as Plans 2–3).**

## Global Constraints

- One file, no external requests; `dist/index.html` ≤ 1.5 MB; `<title>Canteen Sim</title>`, `lang="en"`.
- `src/sim` and `src/batch` import no three/preact/uplot and use no DOM globals (lint).
- Theme tokens: complete light palette on `:root`; dark under `@media (prefers-color-scheme: dark)` guarded by
  `:root:not([data-theme="light"])` and again under `:root[data-theme="dark"]`; scene colour tokens are `#rrggbb`.
- UI formatting uses integer math or a fixed `en-GB` locale; never a locale-sensitive call without a locale.
- Artifact sandbox (from the Artifact page contract): downloads, `alert/confirm/prompt`, `#key=value` hashes and the
  query string do not work there. Every export therefore also offers **Copy**; sharing inside the artifact uses the
  settings code; storage access is wrapped in try/catch.
- 16 px side gutter, no horizontal page scroll at 375 px; A stacked above B below 900 px.

## Review Focus

1. **Theme switch mid-run** (system → dark → light). Expected: materials, instance colours and labels update; text
   contrast ≥ 4.5:1. Test: Task 8 Playwright.
2. **Restart / slider release during Skip-to or a batch.** Expected: no double engines, no leaks, UI consistent.
   Test: Task 3 unit + Task 8 smoke.
3. **Pasted settings code from a newer model / garbage.** Expected: rejected whole with the §9.4 message, settings
   unchanged. Test: Task 2.
4. **No WebGL / context lost.** Expected: §11.10 messages, counters keep running, no `console.error`. Test: Task 8.
5. **Artifact sandbox** (no downloads, stripped hash, worker CSP). Expected: Copy fallbacks, settings code works,
   batch completes via fallback with identical hashes. Test: Task 8 fallback suite.

## Tasks

1. **Build and shell:** dependencies, `vite.config.ts` (single file, inline IIFE worker, `__BUILD_SHA__`,
   `__MODEL__`), `index.html`, `src/main.tsx`, `src/ui/theme.css` tokens, `src/ui/labels.ts`, `src/ui/format.ts`
   (clock via integer math); lint boundaries. Tests: clock formatting, token format `#rrggbb`, labels present.
2. **Config sharing:** `src/config/clamp.ts` (§9.2 clamp order), `url.ts` (hash + base64url settings code, only
   non-default values + seed + `v`, `m`), `load.ts` (unknown keys ignored, clamps with notices, blocked repairs,
   model-version notice, JSON import/export), `assumptions.ts` (§15 ledger). Tests: round trips, invalid/newer codes
   rejected, repairs, every §15 bullet present.
3. **Playback controller:** `src/ui/controller.ts` — two engines, frame loop (tick alternation, 8 ms budget,
   "running at N×"), Skip-to in slices with cancel, Restart, A-slider release, end-of-lunch detection, engine
   exception capture. Tests with a fake clock: A and B always end a frame on the same tick; chunked skip equals
   direct; restart discards engines.
4. **Renderer:** `src/render/*` — one WebGLRenderer, two scenes, scissored viewports; procedural props; instanced
   people/trays/seat tints/rings/objects; waiter placement; walked-away fade; labels atlas; cameras (3/4, top, follow;
   linked orbit); analytic picking; theme application; pixel-ratio fallback; context-loss handling.
5. **Live UI:** top bar, banners, viewports with A slider and legend, live counters (merged table when narrow),
   free-flow advantage strip, seat-state time series (uPlot, Show table), end-of-lunch card, How this works, hover
   cards, error states, keyboard (Space).
6. **Settings and Assumptions:** drawer generated from `META` (groups, units, ranges, warnings, Load readout),
   presets, codes/links/JSON (Copy fallbacks), saved scenarios; Assumptions drawer with Change links.
7. **Batch view and evidence:** picker (reservation / sensitivity, n), time estimate, progress, cancel; primary cards
   with sentences, CI and W/T/L; difference charts with CI bands and Show table; group-size and cohort tables;
   sensitivity chart; CSV (Download + Copy); Evidence line and panel from `src/generated/evidence.json`, re-run check.
8. **Self-test, golden hashes and Playwright:** `?selftest=1`, `npm run golden:update`, Playwright suites: smoke,
   locale, narrow layout, URL/code round trip, 2-seed batch, fallback (CSP `worker-src 'none'`, sandboxed iframe),
   no-WebGL, evidence hashes, cross-browser golden hashes.
9. **README and publishing:** README; artifact variant of the build (skeleton-less body); publish privately; record the
   URL in the README.
