# Visibility roles v1: when seeing farther changes reservation outcomes

Separate research experiment on Model 2. Generated by `npm run research`. No real canteen pilot or empirical validation. [Protocol and predefined contrasts](../research-protocol.md).

600 complete runs, 8 factor combinations, 30 fresh paired lunches per comparison at both 50% and 100% reservation. All 16 comparisons and 28 predefined contrasts are included. No missing or truncated runs. Seeds start from 100001 using batchSeeds; the original sensitivity block starts from 1.

## Reading the mechanism

At 100% reservation with the seating check on, the leaving gap is 4.84 [4.384, 5.304] pp with both ranges at 10 m; 21.07 [20.108, 22.031] pp when only claimers see 20 m; 5.23 [4.772, 5.686] pp when only food-searchers see 20 m; and 20.94 [19.981, 21.898] pp with both at 20 m. Compare the role contrasts below to distinguish these mechanisms.

With both ranges at 20 m, the gap is -0.04 [-0.144, 0.074] pp when the seating check is off. With it on, the reservation change in door leaving is 33.44 [32.339, 34.535] pp and in queue leaving is -12.50 [-12.959, -12.035] pp. Fewer queue departures can reflect fewer people entering.

Success and unavailable-seat diagnostics describe intermediate outcomes; they do not by themselves establish mediation. Role and door interventions identify effects within this simulator, conditional on all unchanged rules. Mean food-carrying times compare the people served in each canteen, who may differ. These measures cannot be collapsed into a policy winner without a stated value judgement.

## Reproduce and audit

- `src/research/visibility-plan.ts`: exact factors, default configuration and seed derivation.
- `docs/studies/visibility-roles-v1-audit.json`: configuration per case, seeds, all run metrics and hashes, diagnostics, and exact paired outcome values.
- `src/generated/research.json`: compact summaries, all contrasts and source/plan identity.
- `npm run research -- --check`: fresh 600-run comparison with all published artifacts.
- `npm run research -- --from-audit`: provenance-checked reconstruction only, for prose changes; not a fresh simulation.
- Unit tests reconstruct every result, check all planned cells and verify that equal role ranges reproduce Model 2. The sanity suite reruns the first seed in every block with invariants enabled.

The interactive animation and its estimates remain Model 2. The separate role variants cannot be loaded using Model 2 settings codes. A hash must be read with its model/experiment identity and settings.
