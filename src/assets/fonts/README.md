# Noto Sans Thai Looped

`noto-sans-thai-looped-thai-400.woff2` is the Thai subset of Noto Sans Thai Looped 2.000,
provided by [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+Thai+Looped).
Copyright 2022 The Noto Project Authors (https://github.com/notofonts/thai).
See `OFL.txt` for the SIL Open Font License 1.1. The full copyright and licence text is also
in the font's name table (ID 13), so it accompanies the font inside the standalone HTML.

Source retrieved 2026-10-05:
https://fonts.gstatic.com/s/notosansthailooped/v16/B50iF6pOpWTRcGrhOVJJ3-oPfY7WQuFu5R36MIjwurFMX_p0KVmQBWnPNHjjNyJ9-g.woff2

FontTools 4.63.0 was used to subset Unicode U+0E00–0E7F (retaining shaping features),
instantiate `wght=400`, and embed `OFL.txt` as name ID 13 for platform 3, encoding 1, language 0x409.
The browser synthesises heavier weights. Latin characters use the existing system font stack.
This single regular face keeps the offline app within its 1.5 MiB size budget.
